VDS - PERBAIKAN LIVE SYNC

Perubahan:
- Realtime websocket tetap menjadi jalur utama untuk update langsung.
- Pemeriksaan cadangan get-sync-events tetap berjalan setiap 30 detik walaupun status channel sudah SUBSCRIBED.
- Ini menangani kondisi channel terlihat tersambung tetapi event database tidak diterima oleh browser.
- Polling hanya mengambil event baru (after_id), bukan mengunduh seluruh app_state.

Pemasangan:
1. Ekstrak ZIP.
2. Ganti file 1-VERCEL/index.html di project GitHub dengan file dari folder ini.
3. Commit/push ke branch yang dipakai Vercel.
4. Tunggu deployment selesai, lalu buka ulang VDS di kedua komputer.
5. Uji: input satu transaksi di Admin. User harus melihatnya langsung via Realtime atau paling lambat sekitar 30 detik melalui pemeriksaan cadangan.

Catatan:
- ZIP ini hanya mengubah frontend. Tidak menjalankan SQL migration dan tidak mengubah Edge Function.
- Pemeriksaan cadangan menambah sekitar 2 panggilan API per menit per komputer yang sedang membuka website. Realtime tetap menjadi jalur utama.
