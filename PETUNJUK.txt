VDS - PERBAIKAN PEMBACAAN IZIN ARDI

Isi ZIP hanya file frontend yang diperlukan:
- index.html                 -> untuk root repository GitHub/Vercel
- 1-VERCEL/index.html        -> salinan identik untuk folder 1-VERCEL

CARA UPDATE:
1. Backup index.html lama.
2. Ganti index.html di ROOT repository GitHub dengan index.html dari ZIP.
3. Jika repository juga menyimpan 1-VERCEL/index.html, ganti dengan file dari folder 1-VERCEL agar keduanya sama.
4. Commit dan push, lalu tunggu Vercel deploy selesai.
5. Buka VDS, lakukan Ctrl+Shift+R, lalu cek Manajemen Akun > Atur Izin Ardi.

Perbaikan: nama key permission dicocokkan tanpa membedakan huruf besar/kecil
(misal SITEBIDDING dan siteBidding dianggap sebagai izin yang sama).
Tidak ada perubahan SQL, Edge Function, data Supabase, atau kode Live Sync.
