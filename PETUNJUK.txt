UPDATE VDS – RINCIAN LEBIH BAYAR & NOMOR TRANSAKSI

1. Ganti file 1-VERCEL/index.html pada repository GitHub dengan file dari folder 1-VERCEL di ZIP ini.
2. Commit ke branch main dan tunggu deployment Vercel selesai.
3. Update tampilan ini menghilangkan tiga kartu ringkasan LEBIH BAYAR CASH / TRANSFER / QRIS dari halaman Live Bidding dan Live Laporan Dana.
   Nilai lebih bayar transaksi tetap dihitung dan disimpan; hanya kartu ringkasannya yang disembunyikan. Rincian Dana tetap menjadi tempat melihat detailnya.
4. Untuk memulai ulang nomor setelah data testing dikosongkan, buka Supabase > SQL Editor, lalu jalankan RESET-NOMOR-SETELAH-TESTING.sql SATU KALI.
   Pastikan transaksi testing memang sudah kosong sebelum menjalankan SQL tersebut.
5. Setelah reset:
   - Bidding: BID NO berikutnya 01 dan Nota 2601.
   - Dana Paramita: ORDER NO berikutnya 01 dan Nota 26001.
6. Refresh website dengan Ctrl+F5 setelah deployment.

PENTING:
- File HTML tidak mereset counter database secara otomatis.
- SQL reset hanya untuk dipakai setelah clear testing; jangan jalankan ketika transaksi asli sudah mulai dicatat.
- Tidak ada perubahan pada Supabase Edge Function atau logika Live Sync.
