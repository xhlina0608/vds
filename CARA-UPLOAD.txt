CARA UPLOAD VDS - HAPUS FITUR SPONSOR

1. Backup repository GitHub terlebih dahulu.
2. Buka ZIP ini dan ambil index.html.
3. Di repository GitHub VDS, buka index.html pada ROOT repository (bukan subfolder).
4. Replace seluruh isi/file index.html dengan file dari ZIP ini.
5. Commit perubahan.
6. Tunggu Vercel deployment Production selesai.
7. Buka website dan tekan Ctrl+Shift+R.

JANGAN menjalankan SQL migration. JANGAN menghapus tabel app_state atau data transaksi.
Data sponsor lama di Supabase tidak dihapus; hanya fitur/menu aplikasinya yang dihilangkan.
