VDS - Dana Paramita Single Copy Editor

Perubahan:
- Dana Paramita hanya menampilkan satu set elemen editor: Nama bidder, Nominal, Nomor barang, Nomor invoice, dan Kasir.
- Bidding tetap menampilkan elemen rangkap 1 sampai 4.
- Tampilan dan cetak Dana Paramita tetap satu rangkap.

Upload index.html ini untuk mengganti index.html di repository GitHub VDS, lalu tunggu deploy Vercel dan lakukan Ctrl+F5.
