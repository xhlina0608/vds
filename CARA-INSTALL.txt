VDS - FITUR DATA SPONSOR BERSAMA

Paket ini memperbarui website gabungan Bidding + Dana Paramita. Kedua website akan memakai satu data sponsor yang sama melalui app_state site=sponsor.

1. BACKUP file website dan Edge Function yang sekarang.
2. Vercel: ganti file 1-VERCEL/index.html ke project website Bidding/Dana Paramita yang sedang dipakai, lalu deploy.
3. Supabase: Edge Functions > vds-api > Code. Ganti isi dengan 2-SUPABASE/index.ts lalu Deploy.
4. Tidak ada SQL migration. Tidak menghapus tabel atau data lama.
5. Login, buka Data Sponsor dan Data Sponsor Barang dari Bidding. Tambah data uji, lalu buka Dana Paramita dan pastikan data yang sama tampil.
6. Hanya setelah tes berhasil, pertimbangkan menonaktifkan project/website sponsor lama. Jangan hapus database app_state atau baris site=sponsor.

Catatan: akses data bersama diberikan kepada akun yang memiliki akses Bidding atau Dana Paramita. Data lama pada app_state site=sponsor (donors/sponsors) tetap dipakai. Jika data sponsor barang lama hanya ada pada state lokal Bidding/Dana, sistem menyalinnya satu kali saat database sponsor bersama masih kosong.
