VDS — PERBAIKAN FINAL 3 WEBSITE
================================

Perbaikan yang ditargetkan:
1. API menerima identitas website sponsor dengan benar. Regex normalizeSite sebelumnya salah escape: huruf "s" dianggap pemisah, sehingga "sponsor" berubah menjadi "ponsor" dan ditolak.
2. Pergantian website dilakukan di TAB YANG SAMA. Tidak membuka tab baru, tidak perlu login ulang, dan tidak kembali ke halaman pilih website akibat race session/handoff.
3. Data Bidding, Dana Paramita, dan Sponsor tetap memakai penyimpanan terpisah berdasarkan site.

ISI PAKET
---------
1-VERCEL/index.html  -> ganti file index.html pada repository GitHub/Vercel.
2-SUPABASE/index.ts  -> ganti source Edge Function vds-api di Supabase.
3-BACKUP/            -> source sebelum perbaikan untuk rollback.

CARA PASANG
-----------
A. GitHub/Vercel
1. Buka repository yang terhubung ke Vercel VDS.
2. Ganti isi index.html dengan file 1-VERCEL/index.html.
3. Commit/push dan tunggu deployment selesai.

B. Supabase
1. Buka project gmpedvbzmgrpwsgsyszj.
2. Edge Functions -> vds-api -> Code.
3. Ganti seluruh source dengan 2-SUPABASE/index.ts.
4. Deploy function vds-api.

JANGAN jalankan SQL migration, jangan hapus tabel/data, jangan ganti Supabase URL/key/secrets.

TES SETELAH DEPLOY
------------------
1. Login sekali.
2. Buka Bidding, pastikan data lama tampil.
3. Klik Pilih Website -> pilih Dana Paramita. Harus berpindah di tab yang sama tanpa login ulang.
4. Klik Pilih Website -> pilih Data Sponsor. Harus terbuka tanpa pesan "Website tidak valid".
5. Kembali ke Bidding dan Dana untuk memastikan keduanya tetap normal.

Catatan: file telah diperiksa secara statis. Hasil live baru dapat dipastikan setelah kedua file dideploy ke Vercel dan Supabase.
