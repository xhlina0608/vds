VDS MOBILE-FIRST UPDATE\n=======================\n\nUpdate frontend untuk tampilan HP dan tablet. Menggunakan basis VDS-RESPONSIVE-UPDATE.\nPerubahan: navigasi ringkas, toolbar menyesuaikan layar, form menjadi satu kolom, tombol lebih mudah disentuh, modal ramah HP, dan tabel dapat digeser hanya di area tabel (bukan seluruh halaman).\n\nCARA PASANG:\n1. Backup index.html aktif di root repository GitHub.\n2. Ekstrak ZIP ini dan ganti index.html di ROOT repository dengan index.html dari ZIP.\n3. Commit/push ke branch main dan tunggu Vercel berstatus Ready.\n4. Buka website dari HP, lalu refresh. Jika masih tampilan lama, tutup tab dan buka kembali.\n\nTIDAK PERLU:\n- Tidak perlu mengubah Supabase Edge Function.\n- Tidak perlu menjalankan SQL migration.\n- Tidak mengubah database, data transaksi, Live Sync, stok, atau perhitungan.\n\nCATATAN TABEL:\nUntuk menjaga semua kolom/data tetap tersedia di layar HP, geser tabel ke kiri/kanan hanya pada area tabel. Seluruh halaman dan jendela browser tidak ikut melebar.\n
